# 缺氧种子演算器 · Windows 预览版

这是配合 ONI Save Lab 网页使用的本机工具。无需安装 Unity 编辑器、Node.js、.NET 或手动安装游戏模组。

## 使用

1. 解压整个压缩包，双击 `OniSeedCompanion.exe`。请保留旁边的 `OniSeedWorker.dll`。
2. 工具会尝试寻找 Steam 版《缺氧》。若没有找到，选择包含 `OxygenNotIncluded.exe` 的完整游戏安装目录。
3. 首次启动会复制游戏运行资源到独立缓存，需要额外磁盘空间。游戏原目录、模组目录和已有存档不作修改。
4. 等待状态卡片显示「演算器已就绪」，保持窗口打开。
5. 点击工具窗口的「打开网页」，会直接进入种子演算页面。普通首页仍默认隐藏入口；若手动打开首页，也可以按 F12 → Console 执行：

```javascript
localStorage.setItem('oni.seedCalculator', '1'); location.reload();
```

6. 点击「从种子演算世界」，输入种子、星群或完整坐标码，并选择自己安装和可使用的 DLC。完成后网页显示原生生成的地图和间歇泉统计。

浏览器可能询问是否允许网页访问本地网络，需要自行允许才能连接。工具只监听 `127.0.0.1:5191`，不向公网开放。若端口被以前的 Node/Unity 测试服务占用，先退出旧服务。

## 等待时间

0.2 版会在填写种子、选择 DLC 时提前预载资源，也会在查看结果时准备下一次演算。同一引擎和输入的已完成种子直接读取缓存。请同时更新网页和工具，旧工具不支持提前预载。

本机 9 星球测试：冷启动约 33 秒，预载后提交约 16 秒；实际时间取决于电脑、种子和 DLC。首次复制运行资源、网页下载及高清地图加载另计。预载会占用内存，暂时不用时可以关闭工具窗口。

## 结果与运行条件

- 生成使用安装版游戏的运行时、SimDLL、世界生成模板和原生间歇泉配置。未重新实现近似随机算法。
- 工具在自己的运行副本中加入任务入口和输出隔离；不会把模组装到游戏目录，也不更改游戏原有的内容可用性或账号验证逻辑。若运行时要求 Steam，请正常启动并登录 Steam。
- 当前验证对象为 Windows x64、Unity 6000.3.5f2 的安装版。预览版仍需扩充其他游戏版本的兼容测试；接口不兼容时会报错。
- 工具不随包分发游戏本体、游戏程序集、SimDLL 或 DLC。需要用户拥有完整安装资源；仅有一个游戏快捷方式或 exe 不够。
- 缓存绑定游戏生成代码、SimDLL、生成资源和工具组件版本。相同输入重复查看可复用已完成结果；游戏更新后请重启工具。
- 输出默认在 `%LOCALAPPDATA%/OniSeedCompanion`。`jobs` 保存每次演算的原生 `.sav`、进度、引擎日志和原生参数核对快照；`runtimes` 是独立运行副本。
- 生成结果是用于地图和资源预览的新世界，不包含玩家原来的殖民地进度。
- 关闭窗口会停止本工具正在执行的演算，不会结束玩家从其他位置启动的游戏进程。

隐藏网页入口：

```javascript
localStorage.removeItem('oni.seedCalculator'); location.reload();
```

## 桌面界面（0.2.1）

窗口采用统一的黑色卡片、轻微阴影和深色标题栏，集中显示服务状态、游戏位置和运行记录。已有原生演算服务运行时会直接连接；若端口被其他程序占用，会显示中文原因和重试按钮。详细启动错误保存在工具缓存目录的 launcher.log。
